# Revision guide for this completed batch

This is a study aid, not a prediction of the exam paper. Read the answer, explain it aloud without looking, then write a short answer or run the code from memory.

## Suggested order

1. **Data Visualization 01:** perception, data types, pipeline and audience. Sketch one good and one misleading chart.
2. **Data Visualization 02:** cleaning rules, Series/DataFrame, descriptive statistics and denominators. Re-run clean_logs.py and explain every rejected row.
3. **Data Visualization 03:** Figure/Axes/Axis, distributions and encodings. Explain why area is harder to compare than common-scale position.
4. **Data Visualization 04-05:** callbacks, client/server execution, dashboards, hierarchies and storytelling. Draw a dashboard for one concrete user decision.
5. **MEAN 01:** event loop, modules, npm and asynchronous file I/O. Predict the three programs' output order before running them.
6. **MEAN 02:** props/state, SPA navigation and render/commit. Explain what changes in the counter app after a click.
7. **MEAN 04:** routes, parameters, nested outlets, one shared service, HTTP states and lazy loading. Rebuild the portal and demonstrate every route.
