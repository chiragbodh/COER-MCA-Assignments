# Exam and viva revision guide

For each answer, define the concept, explain the mechanism, give an example and state one limitation. Practice without looking at the solution, then compare.

## AIML order

1. Unit I: semantics, forms, box model, Flexbox, AI/ML/LLMs and structured prompts. Rebuild the practical page from memory.
2. Unit II: cloud/local inference, quantization, context, design tokens, Grid and image-to-code limitations.
3. Unit III: event loop, values, scope, coercion, arrays, this, DOM events and errors. Predict outputs before running examples.
4. Assignment 4: indexing, RAG, agent workflows, refactoring and review. Explain why ignore files are not complete security boundaries.
5. Assignment 5: builds, asset paths, SPA routes, CI, licenses, attribution and prompt injection.

## MVC practice

Trace browser → front controller → request/router → middleware → controller → model/PDO → view/JSON.

- Lab 1: locate student/course/faculty/department responsibilities.
- Lab 2: show invalid input, preserved values, uploads and a 303 redirect.
- Lab 3: explain safe routes and 404 versus 405.
- Lab 4: demonstrate CRUD, filters, sorting and pagination; explain bound values versus allowlisted identifiers.
- Lab 5: compare roles, hashing, login, session rotation and logout.
- Lab 6: demonstrate rejected CSRF, escaped comments and rejected fake images.
- Lab 7: run the Postman sequence and explain API status codes.

## Data Visualization and self-tests

Revise perception, cleaning/EDA, chart selection, interaction and dashboard storytelling. Re-run Pandas and explain rejected records. Study a topic, close the answer, write your explanation, solve a variation and note mistakes. For viva, show a real code path and output.

The original MEAN and Java repositories remain the sources for completed subjects. A later exam plan should use actual paper dates, syllabus, question banks and weak topics; no exam schedule is assumed here.
