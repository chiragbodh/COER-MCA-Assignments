UNIT III: JAVASCRIPT & AI DEBUGGING
Question 1  [Total: 14 Marks]
(a) How does the JavaScript Execution Runtime and Event Loop work? Trace the step-by-step path of regular code, the Call Stack, Web APIs, Microtask Queue (Promises), and Macrotask Queue (setTimeout). [Understand | 7 Marks]
(b) Analyze a JavaScript code snippet containing setTimeout, Promise.resolve, and console.log. Explain the exact console log order and why it happens based on Event Loop rules. [Analyze | 7 Marks]
Question 2  [Total: 14 Marks]
(a) What is the difference between Primitive Data Types and Reference Types in JavaScript? How are they stored in Stack and Heap memory, and what is the difference between pass-by-value and pass-by-reference? [Understand | 7 Marks]
(b) Compare var, let, and const. Explain block scope, function scope, variable hoisting, and the Temporal Dead Zone (TDZ) using short code examples. [Analyze | 7 Marks]
Question 3  [Total: 14 Marks]
(a) What is the difference between loose equality (==) and strict equality (===) in JavaScript? Explain type coercion and unusual results like [] == false, null == undefined, and NaN === NaN. [Understand | 7 Marks]
(b) Compare conditional structures: if-else, switch-case, ternary operators, and Nullish Coalescing (??) versus Logical OR (||). Provide an example where ?? prevents a bug that || would cause. [Apply | 7 Marks]
Question 4  [Total: 14 Marks]
(a) Compare JavaScript loops: standard for, while, for...in, and for...of. Why is for...in bad for arrays, and how does for...of work with iterables? [Analyze | 7 Marks]
(b) Compare array methods: map(), filter(), reduce(), and forEach(). Write a JavaScript snippet using filter() and reduce() to calculate the total cost of active products. [Apply | 7 Marks]
Question 5  [Total: 14 Marks]
(a) How are function parameters handled in modern JavaScript? Compare default parameters, Rest parameters (...args), and the older arguments object. [Understand | 7 Marks]
(b) Compare Arrow Functions with Traditional Functions. How does lexical this binding work in arrow functions, and how does it prevent scope issues in async callbacks? [Analyze | 7 Marks]
Question 6  [Total: 14 Marks]
(a) Explain DOM Event Handling and the 3 phases of Event Propagation: Capturing, Target, and Bubbling. What does event.stopPropagation() do? [Understand | 7 Marks]
(b) What is Event Delegation? Demonstrate how adding a single click event listener to a parent <ul> element can handle clicks for hundreds of child <li> elements using event.target. [Apply | 7 Marks]
Question 7  [Total: 14 Marks]
(a) What is the Comment-to-Code programming approach? How do inline code comments act as prompts for AI coding assistants, and why does comment quality matter? [Understand | 7 Marks]
(b) Write a complete JSDoc comment for an async JavaScript function (fetchUserData). Show how parameter types (@param), return types (@returns), and errors (@throws) help AI autocomplete engines. [Apply | 7 Marks]
Question 8  [Total: 14 Marks]
(a) Explain common JavaScript error types: SyntaxError, ReferenceError, TypeError, RangeError, and URIError. Provide code examples that trigger each error. [Analyze | 7 Marks]
(b) How does try...catch...finally exception handling work? What happens if a finally block contains a return statement that conflicts with a return in the try block? [Analyze | 7 Marks]
Question 9  [Total: 14 Marks]
(a) What is the best strategy for using AI to fix unhandled Promise rejections and async/await crashes? What details (error stacks, variables, context) should you include in your prompt? [Apply | 7 Marks]
(b) Write a prompt that provides a Node.js stack trace to an LLM, asking it to diagnose a memory leak caused by unremoved event listeners without changing main business logic. [Create | 7 Marks]
