UNIT I: WEB FUNDAMENTALS & ESSENTIALS OF AI
Question 1  [Total: 14 Marks]
(a) How did web layout design evolve from HTML4 to HTML5? Explain semantic tags (<header>, <main>, <article>, <section>, <aside>, <footer>) and why they improve page structure, accessibility for screen readers (ARIA), and SEO compared to using only <div> tags. [Understand | 7 Marks]
(b) Explain HTML5 form features. Detail standard input types (email, number, url, date) and validation attributes (required, pattern, min, max). How does browser-side form validation save server resources? [Apply | 7 Marks]
Question 2  [Total: 14 Marks]
(a) Explain the CSS Box Model in detail (content, padding, border, and margin). Compare box-sizing: content-box with box-sizing: border-box, and show how each calculates an element's total width. [Understand | 7 Marks]
(b) Explain how CSS Flexbox works. What are the Main Axis and Cross Axis? How do properties like justify-content, align-items, align-self, flex-grow, flex-shrink, and flex-basis help build responsive layouts? [Apply | 7 Marks]
Question 3  [Total: 14 Marks]
(a) Explain the difference between Artificial Intelligence, Machine Learning, Deep Learning, and Generative AI. How is Generative AI changing software development and web engineering? [Analyze | 7 Marks]
(b) How do Large Language Models (LLMs) generate code? Explain Transformers, self-attention mechanisms, and how LLMs predict the next word or line in code. [Understand | 7 Marks]
Question 4  [Total: 14 Marks]
(a) What are the four core parts of a developer prompt (Instruction, Context, Input Data, and Output Indicator)? Write a structured prompt requesting a CSS Flexbox card component. [Apply | 7 Marks]
(b) Compare Zero-shot, Few-shot, and Chain-of-Thought (CoT) prompting. Show how including code examples (few-shot) in a prompt helps an AI generate better HTML5 templates. [Analyze | 7 Marks]
Question 5  [Total: 14 Marks]

Question 6  [Total: 14 Marks]
