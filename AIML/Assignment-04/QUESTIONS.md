Assignment 4
AI for Web Development
BCA 2nd Semester (Session 2025-2024)
What are AI-Native IDEs (like Cursor or Windsurf)? How do they differ from standard editors using AI plugins (like VS Code with Copilot)? Focus on indexing and workflow integration. 
How does the "agentic loop" work inside an AI editor? How does it read your prompt, inspect files, run tools, and display code diff previews automatically? 
What is a Context Mapping Tree in workspace AI tools? How do syntax trees (ASTs), symbol tables, and module export graphs help the AI understand an entire software project? 
How does an AI workspace agent use dependency maps to figure out which component files will break when a shared helper function is updated? 
How does local project indexing work in AI code editors? Explain how code files are split into chunks, converted into vector embeddings, and stored locally for quick retrieval. 
How does Retrieval-Augmented Generation (RAG) work inside an IDE when a developer asks a project-wide question like "Where is user login authentication handled?" 
How do keyboard shortcuts for inline AI prompts (like Cmd+K or Ctrl+I) help developers modify and refactor code directly inside their active file without breaking focus? 
Evaluate visual inline diff review interfaces (Accept / Reject code popups). How do green/red code comparison views help prevent errors during AI refactoring? 
How do real-time code autocomplete tools work? How do fast, smaller AI models generate single-line and multi-line suggestions in under 100 milliseconds? 
How do recent cursor movements, open editor tabs, and nearby file code help AI tools make more accurate code completions? 
What are Autonomous Multi-File Composers? How can these AI agents create, edit, and delete files across an entire repository from a single user prompt? 
Trace the step-by-step process an AI agent follows when building a new feature: Task Planning -> Tool Selection -> File Editing -> Terminal Command -> Error Correction. 
How do AI workspace agents manage multi-file refactoring? What safety checks must the agent perform when renaming shared database schemas or function names across many files? 
Write a step-by-step prompt that instructs an AI composer to migrate a project from plain JavaScript (.js) to typed TypeScript (.ts), updating imports and configs. 
How do automated Git summary tools work? How do they read staged changes (git diff) and write structured commit messages following Conventional Commit rules?
How do AI-generated Pull Request (PR) descriptions improve code reviews by summarizing architectural changes, endpoints, and test plans? 
What are the trade-offs between system performance (CPU, RAM, Disk usage) and search accuracy when an AI indexes a very large code repository? 
Design an IDE configuration/policy that blocks AI workspace agents from indexing sensitive files like .env, passwords, or private modules
Compare inline auto-completion with multi-file AI composers in terms of developer control, risk of code breakage, and required context size. 
What are the risks of developers over-relying on autonomous AI composers for setup and refactoring? Could this cause coding skills to weaken over time?
