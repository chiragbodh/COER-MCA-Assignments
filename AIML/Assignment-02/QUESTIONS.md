UNIT II: AI PLATFORMS & PROMPT DESIGN
Question 1  [Total: 14 Marks]
(a) Compare Cloud AI services (e.g., OpenAI API, Claude) with Local AI running on your computer (e.g., Ollama with Llama 3). Focus on response speed, hardware requirements, cost, and data privacy. [Analyze | 7 Marks]
(b) How do local AI runners work? Explain how model quantization (formats like GGUF) lets normal consumer computers run large coding models efficiently. [Understand | 7 Marks]
Question 2  [Total: 14 Marks]
(a) What is Token Context Selection in LLMs? How do tokenizers break down source code into tokens, and what happens when code exceeds the context window limit? [Understand | 7 Marks]
(b) What is the "Lost in the Middle" problem in large context windows? How should you structure your prompt (putting critical rules at the top or bottom) so the AI doesn't ignore key instructions? [Apply | 7 Marks]
Question 3  [Total: 14 Marks]
(a) What is Aesthetic Prompt Mapping? How do you translate descriptive design styles (like "minimalist", "glassmorphism", or "cyberpunk") into clear CSS properties in an AI prompt? [Apply | 7 Marks]
(b) Write a detailed prompt that forces an AI model to generate a "Glassmorphic Dashboard Card" using specific CSS attributes (backdrop-filter, background opacity, border-radius, box-shadow). [Create | 7 Marks]
Question 4  [Total: 14 Marks]
(a) What is Brand System Enforcement in automated UI design? How can you include design tokens (colors, font scales, spacing, shadows) in system prompts to maintain visual consistency? [Understand | 7 Marks]
(b) How do you enforce specific colors in prompt engineering? Show how providing exact Hex color codes prevents an AI model from picking random, unwanted colors. [Apply | 7 Marks]
Question 5  [Total: 14 Marks]
(a) How do you prompt an AI to generate mobile grid layouts? Compare CSS Grid vs CSS Flexbox prompt instructions for a 12-column mobile-first grid. [Analyze | 7 Marks]

Question 6  [Total: 14 Marks]
